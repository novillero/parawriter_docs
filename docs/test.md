|Параметр                      |Значение      |

### Критерии оценки условия алерта

|Параметр                      |Значение      |
|:----------------------------:|:------------:|
|Период ожидания для срабатывания алерта |1 минута |
|Статус алерта при отсутствии данных для проверки |No Data |
|Статус алерта при тайм-ауте или ошибке выполнения |Error |

* Период ожидания для срабатывания алерта: **1 минута**
* Статус алерта при отсутствии данных для проверки: **No Data**
* Статус алерта при тайм-ауте или ошибке выполнения: **Error**
